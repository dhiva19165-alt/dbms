- Ex 5: Procedures and Functions
- Ex 6: Triggers
- Ex 7: Library Database Schema
- Ex 8: Exception Handling
- Ex 9: NoSQL Examples (Key-Value, Column, Document, Graph)
- Ex 10: MongoDB CRUD Operations
- Ex 11: Cassandra Cluster Setup and CQL
- Mini Project: Railway Reservation System
